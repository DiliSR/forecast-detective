# Papers behind the knowledge base

The PDFs are not published here (copyright). Download them and place them in this folder, then run
`python scripts/build_index.py`. The file names below are the ones the index expects.

| File | Paper |
|---|---|
| `shap_lundberg2017.pdf` | Lundberg & Lee (2017), A Unified Approach to Interpreting Model Predictions (SHAP), arXiv:1705.07874 |
| `treeshap_lundberg2019.pdf` | Lundberg et al. (2020), From local explanations to global understanding with explainable AI for trees (TreeSHAP), arXiv:1905.04610 |
| `lime_ribeiro2016.pdf` | Ribeiro, Singh & Guestrin (2016), "Why Should I Trust You?" (LIME), arXiv:1602.04938 |
| `integrated_gradients_sundararajan2017.pdf` | Sundararajan, Taly & Yan (2017), Axiomatic Attribution for Deep Networks (Integrated Gradients), arXiv:1703.01365 |
| `timeshap_bento2021.pdf` | Bento et al. (2021), TimeSHAP: Explaining Recurrent Models through Sequence Perturbations, arXiv:2012.00073 |
